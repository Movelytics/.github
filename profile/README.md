# Movelytics

We build [PoseTracker](https://www.posetracker.com), a real-time pose estimation SDK and API for fitness, wellness and rehab apps. It runs on-device, with no cloud, and is made for React Native, iOS, Android and web.

- **Keypoints are free**, with no API key: 17 body keypoints per frame, computed on the device.
- **The engine** on top counts repetitions, scores form and guides the user into the frame. It needs an API key and has a free plan.
